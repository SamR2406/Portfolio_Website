CVE-2025-52183 • Incorrect Access Control

Severity: Medium
Product
SoftPerfect NetWorx 7.3
Vendor
SoftPerfect Pty Ltd
Author
Samuel Giuliano Reale
Date
29 Jul 2025

Description

SoftPerfect NetWorx 7.3 stores credentials in plaintext inside C:\ProgramData\SoftPerfect\NetWorx\NetWorx.db3. Any standard (non-admin) Windows account can read this file, enabling local attackers to extract authentication data without elevated privileges (CWE-284).

Attack Vector: Local standard user.

Impact: Confidentiality High, Integrity None, Availability None.

Proof of Concept

Log in as a standard (non-administrator) Windows user.

Navigate to:

C:\ProgramData\SoftPerfect\NetWorx\NetWorx.db3

Rename the file extension to .txt and open it in a text editor to read the stored credentials in plaintext.
