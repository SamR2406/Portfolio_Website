# Samuel Reale — Developer & Cybersecurity Analyst

This is my personal portfolio website: a terminal-themed showcase of my software development, security research, and vulnerability disclosure work.
It highlights projects written in JavaScript, Python, C#, and other technologies, alongside published CVEs, certifications, and research contributions.

## About the Portfolio

This website is designed to reflect how I work: clean, direct, and security-focused.
It features:

* Terminal-style visual design (Tailwind CSS)
* Smooth startup text animation powered by JavaScript
* Modular structure for easy updates
* Fully responsive layout
* Sections for projects, publications, CVEs, skills, and professional profile

## Tech Stack

* HTML5
* Tailwind CSS
* Vanilla JavaScript
* Responsive layout and animations



## Key Features

* **Scrambled Text Reveal Animation**
  The name appears character-by-character using randomized letters to create a cyber-inspired reveal animation.

* **Project Cards with Previews**
  Each project includes:

  * Technology summary
  * Short description
  * Image preview
  * Link to GitHub repository

* **CVE Disclosure Section**
  Real-world vulnerability write-ups including:

  * Product and vendor
  * Severity
  * Technical explanation
  * Reproduction or proof-of-concept

* **Skills Overview**
  Divided into:

  * Software development
  * Cyber security
  * Systems and operations
  * Professional skills
